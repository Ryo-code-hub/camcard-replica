# 差异分析（Difference Analysis）

> 本文件逐项记录“复刻实现 vs 参考 App”的可观察差异、原因与处置。

## 平台差异

| 差异 | 原因 | 处置 |
| --- | --- | --- |
| 相机路径在模拟器不可用 | iOS 模拟器无摄像头 | 模拟器用 MockCamera（测试图模拟拍摄），真机走系统相机；验收时注明 |
| 相机权限弹窗只在真机出现 | 模拟器无相机硬件 | 以 authorizationStatus 分支逻辑 + 文档说明 |
| CamCard iOS 无法在模拟器安装 | 模拟器无 App Store | Week1 用借来的 iPhone 做黑盒观察，截图留档 |

## 待补充

- UI 像素差异（配色/字号/间距）逐页对比
- OCR 字错率与字段准确率（30–50 张测试名片）
